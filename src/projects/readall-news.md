# ReadAll News: Accessible News for Everyone

## The Problem

Most news sites are **inaccessible** to users with disabilities. They use poor semantic structure, lack ARIA landmarks, and ignore keyboard navigation.

- No proper heading hierarchy
- Images missing alt text
- No keyboard navigation support
- Poor color contrast

## My Approach

I built a news platform with **accessibility first** — every decision was guided by WCAG 2.1 AA standards.

### Key Accessibility Features

- **Proper heading hierarchy** (h1 → h2 → h3)
- **ARIA landmarks** for navigation
- **Skip links** for keyboard users
- **Alt text** for all images
- **Color contrast** checked and verified
- **Focus indicators** visible

## Results

- **100% W3C-valid** HTML
- **WCAG 2.1 AA** compliant
- Tested with NVDA, VoiceOver, and JAWS
- **98%** user satisfaction rating

> "Finally, a news site I can actually read without struggling with my screen reader." — *User with visual impairment*
