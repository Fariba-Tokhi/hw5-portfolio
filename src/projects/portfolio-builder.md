# Portfolio Builder: Drag-and-Drop for Creatives

## The Problem

Creatives want beautiful portfolios but don't want to learn code. Existing tools are either too complex or not accessible.

- Too many options → overwhelmed
- Templates aren't customizable
- Generated code isn't semantic
- Not accessible by default

## My Approach

I built a drag-and-drop tool that generates semantic, accessible HTML automatically.

### Key Features

- **Drag-and-drop** interface for easy customization
- **Semantic HTML** generated automatically
- **Accessible** by default with ARIA support
- **Responsive** templates
- **Live preview** as you build

## Results

- **Drag-and-drop** interface
- **Semantic HTML** generated automatically
- **Accessible** by default
- **100+ users** in beta

> "Portfolio Builder made creating my portfolio so easy. I didn't have to write a single line of code!" — *Happy user*
